git init. -> cria um repositório git na pasta atual
git status -> mostra o status do trabalho (de cada arquivo)
git add nome_arquivo -> adiciona o arquivo para ser commitado
git commit -m "msg" -> faz o commit do que estava para ser commitado
git log -> mostra todo o histórico de commits 

## FLUXO DE TRABALHO
1.criar diretório do projeto
2.iniciar o git dentro do diretório criado
3.editar ou criar arquivos
4.git status
5.git add (nome do arquivo)
6.git status
7.git commit -m "mensagem
8.git status
9.volta para o passo 3
